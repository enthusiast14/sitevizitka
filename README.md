# Flask сайт-визитка

Учебный проект в формате сайта-визитки на Flask. В приложении есть главная страница, база данных с проектами, пользовательская авторизация и административная панель.

## Что реализовано

- Flask backend на Python.
- Jinja2 шаблоны.
- SQLite база данных через SQLAlchemy ORM.
- Светлая и тёмная тема с сохранением выбора в браузере.
- Главная страница с информацией о проекте, портфолио и контактной формой.
- Пользовательская регистрация, вход, выход, личный кабинет и смена пароля.
- Проверка сложности пароля на сервере.
- Ролевая логика: пользовательский кабинет и отдельный административный доступ.
- CSRF-защита для всех POST-форм.
- Админ-вход для управления проектами, просмотра сообщений и включения/отключения пользовательских аккаунтов.
- Базовая клиентская и серверная валидация форм.
- Адаптивная навигация и мобильное меню.

## Запуск

1. Создайте виртуальное окружение:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

2. Установите зависимости:

```powershell
pip install -r requirements.txt
```

3. Запустите приложение:

```powershell
python app.py
```

После первого запуска автоматически создаются база `instance/site.db`, тестовый администратор и несколько стартовых проектов.

## Запуск по сети

Если нужно открыть сайт с этого ПК или другого устройства в одной локальной сети, используйте:

```powershell
python host.py
```

По умолчанию `host.py` запускает приложение на локальном IP-адресе компьютера и порту `5000`.

Если нужно указать адрес и порт вручную:

```powershell
python host.py --host 172.16.0.2 --port 5000
```

После запуска сайт будет доступен именно по адресу:

```text
http://172.16.0.2:5000
```

## Публичная ссылка для преподавателя

Если нужно отправить ссылку человеку вне вашей локальной сети, используйте:

```powershell
public_host.bat
``` 

Или:

```powershell
powershell -ExecutionPolicy Bypass -File .\public_host.ps1
```

Этот скрипт:

- автоматически устанавливает зависимости из `requirements.txt`
- запускает сайт локально на `127.0.0.1:5000`
- поднимает публичный туннель через `cloudflared`
- показывает внешнюю `https://...` ссылку, которую можно отправить преподавателю

Для работы нужен установленный `cloudflared`.

## Данные администратора по умолчанию

- Логин: `admin`
- Пароль: `admin12345`

Рекомендуется переопределить их через переменные окружения:

```powershell
$env:ADMIN_USERNAME="myadmin"
$env:ADMIN_PASSWORD="strong-password"
$env:SECRET_KEY="super-secret-key"
$env:COOKIE_SECURE="1"
python app.py
```

## Основные маршруты

- `/` — главная страница, проекты и форма обратной связи.
- `/register` — регистрация пользователя.
- `/login` — вход пользователя.
- `/account` — личный кабинет пользователя.
- `/admin/login` — вход администратора.
- `/admin` — панель управления.
- `/admin/projects/new` — добавление проекта.

## Как работает админка

1. Откройте `/admin/login`.
2. Введите логин и пароль администратора.
3. После входа откроется панель со статистикой, проектами, сообщениями и таблицей зарегистрированных пользователей.
4. В разделе пользователей можно временно отключать и снова включать доступ к аккаунтам.

## Структура

- `app.py` — обычный локальный запуск.
- `host.py` — запуск на ПК и по локальной сети.
- `app/` — пакет приложения.
- `app/templates/` — HTML-шаблоны Jinja2.
- `app/static/` — CSS, JS и изображения.
- `instance/site.db` — SQLite база данных после первого запуска.
